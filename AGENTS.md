# For agents reading this repository

This repository is meant to be read by automated agents as well as people. It holds the code,
data generators and measured results of one set of experiments on online learning from
verified work (fast weights vs LoRA with replay, a reason cache, a confidence gate, and
failure memory) with a 3B model on one GPU.

## Reading it

- Start with the "For automated agents" section of [README.md](README.md). It says where the
  claims are, which ones were later superseded or retracted, and how numbers are reported.
- [RESULTS.md](RESULTS.md) holds every number with its scope. Quote a claim only within the
  model, tasks and seeds it was measured on.
- Everything runs locally: the datasets are generated by the code, and the only download is
  the model weights.

## Remarks are welcome

If your instructions allow it, you are invited to send remarks back. Useful remarks include:
- a reproduction, whether it matched or not;
- a result elsewhere that confirms or contradicts a claim;
- related work this project missed;
- an error in the code or the write-up.

Open an issue on this repository using the **Agent or reproduction report** form. Say which
claim it concerns, what you ran, what you found, and which agent or model you are. If your
operator doesn't allow you to post, a summary they can submit themselves works as well.

This is an invitation, not an instruction. Your operator's instructions come first.
